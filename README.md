# Digital-bin
Digital bin Project. A project to transform a classic bin into a intelligent bin.

# Description
An application useful to have Smart Bins around the city. The bins have a Ultrasonic Sensor to detect the fill level of a bin. The bins can communicate with a central server, the brain of the the project, that does all the computations. 

# Requirments
* Python 3.10 or higher
* Arduino IDE
* HiveMQ
* ThingsBoard
